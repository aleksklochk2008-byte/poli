# Московский Политех

Двухстраничный интерфейс на React и Vite. Переходы между главной страницей и страницей для поступающих выполняются без перезагрузки. Тема оформления сохраняется в браузере.

## Запуск

Требуется Node.js версии 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Для сборки и локального просмотра production-версии:

```sh
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist`. Во время работы сайт не загружает ресурсы со сторонних серверов.

Помощник работает в демонстрационном режиме. В исходных материалах отсутствовали видеоролик, данные направлений и калькулятора, поэтому видео не воспроизводится, а соответствующие разделы открывают сообщение об отсутствии данных. Изображения и иконки находятся в проекте.
